# Sprint 3 User Testing

## Overview

A new external user-testing round was conducted for Sprint 3 on **29 September 2026**.

The same Google Form used for earlier testing rounds was retained, so the complete response file contains responses from multiple sprints. The Sprint 3 results below were isolated using the response timestamps.

For this round:

- **8 external responses** were collected on 29 September 2026.
- Earlier Sprint 2 responses were excluded from the Sprint 3 calculations.
- A project-team response dated 28 September was also excluded from the external-user results.
- Testing focused on navigation, visual design, discoverability, page clarity and areas users felt could still be improved.

## Dashboard and Page Clarity

All eight Sprint 3 respondents described the Dashboard positively.

Responses included:

- "Yes"
- "Yes, dashboard is clear."
- "yes very neat and professional"

The Drivers, Constructors, Races and Statistics pages were also generally viewed positively. One respondent identified an improvement opportunity: driver names shown elsewhere in the application could link directly to the relevant driver's detail page.

## Positive Feedback

Several consistent positive themes appeared in the Sprint 3 responses:

- navigation was easy and intuitive;
- the interface was described as clean and professional;
- the search feature was highlighted positively;
- race information was easy to find;
- users liked being able to explore individual drivers;
- the overall hierarchy and page structure were considered clear;
- the modern visual design was positively received.

Example feedback included:

> "The overall look of the website is very professional and clean. It works very well."

and:

> "it was intuitive to use"

## Issues and Improvement Opportunities

### 1. Race-detail navigation

One respondent found it difficult to return to the previous location after opening a race:

> "When you click on races and then go into the race you're interested in, its not so easy to navigate back to where you were..."

**Suggested follow-up:** investigate clearer back-navigation or breadcrumb navigation on race-detail pages.

### 2. Driver links and additional driver statistics

One respondent wanted driver names throughout the application to link directly to the driver's detail page.

The same respondent also expected more driver statistics, specifically:

- wins;
- podiums;
- fastest laps.

**Suggested follow-up:** assess whether existing data supports these statistics and whether driver links can be made more consistent across pages.

### 3. Qualifying information

Two separate Sprint 3 respondents specifically identified **qualifying information** as something they expected to find.

This makes qualifying information one of the clearest repeated feature requests in the Sprint 3 round.

**Suggested follow-up:** review the qualifying data already available to the system and determine whether it can be exposed more clearly in the interface.

### 4. Historical seasons

One respondent requested the ability to view information from seasons before 2025.

**Suggested follow-up:** assess whether existing historical data can support a season-selection workflow without significantly expanding Sprint 3 scope.

### 5. Optional light mode

One respondent suggested an optional light theme.

**Status:** useful enhancement idea, but not considered a core Sprint 3 usability problem.

## What Was Not Reported as a Problem

Seven of the eight users reported no general confusion or functionality problem.

This suggests that the main Sprint 3 usability issues are targeted enhancements rather than broad problems with the interface.

## Overall Satisfaction

The free-text satisfaction responses were strongly positive overall.

Responses included:

- "Very satisfied"
- "Extremely satisfied"
- "10/10"
- "5/5"
- "Very satisfied, it has everything needed for a f1 analytics website."

One respondent reported being **60% satisfied**, explaining that they wanted additional driver information. This feedback is reflected in the improvement items above.

## Conclusion

Sprint 3 testing indicates that the application is generally easy to navigate, visually clear and effective at helping users find drivers and races.

The strongest remaining opportunities identified by external users are:

1. clearer navigation from race-detail pages;
2. direct driver-detail links across the application;
3. additional driver statistics;
4. clearer qualifying information;
5. broader historical-season access.

These findings should be used as concrete improvement evidence rather than treating every request as a required Sprint 3 implementation.
